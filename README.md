# SignOut

A Streamlit + Google Sheets sign-in/out kiosk for camp staff: a "Sign In /
Out" board for staff to log themselves in and out, a live "Who's Out" board,
van and group sign-out tracking, an emergency-mode banner, and an admin page
with analytics, archiving, and audit logging.

Every camp-specific detail (name, timezone, van fleet, notifications) is
configured through secrets, not code — see [SETUP.md](SETUP.md) for taking
this from a blank Google Sheet to a working kiosk for a new camp.
